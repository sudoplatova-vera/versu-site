РАЗМЕЩЕНИЕ НА GITHUB PAGES

1. Сохраните копию действующего репозитория перед заменой файлов.
2. Распакуйте этот архив на компьютере. В репозитории sudoplatova-vera/versu-site замените index.html, styles.css и содержимое assets в используемой папке публикации. Если публикация идет из корня, эти файлы должны быть в корне, а не в дополнительной вложенной папке. ZIP как один файл не публикует HTML-сайт.
3. Добавьте пустой файл .nojekyll. Он включен в архив, но может быть скрыт в файловом менеджере.
4. Для возврата на старый адрес удалите прежний файл CNAME из папки публикации, если он остался. В Settings → Pages уберите Custom domain. Новый комплект CNAME не содержит. Проверьте выбранные ветку и папку публикации; используйте действующий источник сборки.
5. Сохраните изменения (commit), дождитесь успешного развертывания в Actions/Pages и откройте https://sudoplatova-vera.github.io/versu-site/ .
6. Проверьте кнопки связи и обе ссылки на PDF, затем откройте страницу на телефоне.

Этот комплект не привязывает versu.pro к GitHub. Статус глобального сбоя GitHub не проверялся.
