# ВЕРСУ — сайт-визитка

Редакция от 01.10.2026. Предпросмотр для согласования дизайна и содержания.

## Просмотр
Откройте index.html в браузере. Все изображения и шрифты локальные; установка зависимостей не нужна. Блоки опыта и форматов раскрываются мышью или клавиатурой.

## Состав
- index.html — содержание и разметка.
- styles.css — адаптивный фирменный стиль.
- assets — оригинальные знак и фотография, локальные шрифты PT Serif и Golos Text с лицензиями.
- .nojekyll — файл для GitHub Pages.

## Размещение
Файлы готовы для статического хостинга, в том числе GitHub Pages. Домен и размещение пока не изменялись. После согласования домена отдельно настроить DNS, HTTPS и адреса canonical / Open Graph / sitemap. Адрес почты не используется как предположение об адресе сайта.

## Проверка
Проверено в Chromium при ширине 1440, 1024, 768, 390 и 320 px: локальные шрифты загружаются, изображения доступны, горизонтального переполнения нет. Раскрытие всех блоков не создает горизонтального переполнения. Проверены якоря и адреса контактов. На реальные мобильные устройства и Safari проверка не распространяется.
